# گزارش آزمون فاز ۲

## پوشش
- ایجاد، ویرایش، حذف و تایید شیفت
- تخصیص و حذف نیرو با ثبت رویداد audit
- رد مدرک منقضی، تداخل زمان، عدم دسترسی و نبود مهارت
- کنترل نقش‌ها و مالکیت ثبت دسترسی پرسنل
- نمایش RTL، واژگان فارسی و تقویم جلالی روزانه/هفتگی/ماهانه

## اجرای محلی
```bash
cd backend && npm ci && npm run typecheck
cd ../frontend && npm ci && npm run typecheck
cd ../../ && npm run run:tests
```

آزمون end-to-end نمونه: ساخت شیفت شب ICU با مهارت ACLS، اعتبارسنجی پرستار، تخصیص و تایید. اجرای وابسته به PostgreSQL و متغیرهای محیطی Docker است؛ نتیجه اجرا باید در CI ثبت شود.
